最近のプロジェクト概要は以下の4つです：

1. **Snowflake を local から dbtで処理 (Doc 1):**
   - SnowflakeにSSHキーを生成し、dbtを通じて接続設定を行う内容。
   - 公開鍵をSnowflakeユーザーに割り当て、データを読み込むための操作が記載されています。

2. **MySQL を追加してAPI 確認 (Docker FastAPI ubuntu) (Doc 2):**
   - Dockerを使ってFastAPIアプリケーションをUbuntu上に構築し、MySQLとの接続を確立するプロジェクト。
   - AlpineからUbuntuへの移行の理由や手順が詳述されています。

3. **Docker構築で実行権限が必要なファイルがあるときのベストプラクティス (Doc 3):**
   - Dockerfileやdocker-composeでのファイルの実行権限についての指針を述べる内容。
   - 2つのパターンでのアプローチが紹介されています。

4. **フロントにUser一覧を表示 (Doc 4):**
   - ユーザー一覧データをバックエンドからフロントエンドに表示する方法について。
   - Reactを使用し、APIからデータを取得するプロセスが記述されています。
